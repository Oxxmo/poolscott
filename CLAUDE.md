# Pool — règles du dépôt (projet perso, voir projet Claude « Projets dev »)


## Contexte
- Projets perso. Stack : Astro, JavaScript sans framework, HTML/CSS, Vercel, Supabase, Python. Pas de React.
- Électronique : ESP32 et ESPHome, modules pré-soudés uniquement (je ne soude pas).

## Façon de travailler
- Livraison par étapes que je valide ; fichiers complets ; numéro de version visible.
- Pour l'électronique : schéma de câblage borne par borne, liste d'achat avec liens, et sécurités logicielles (plafonds, alarmes) avant toute commande d'actionneur.

## Avant de rendre
- Code lancé ou compilé, preuve à l'appui. Si ce n'est pas possible ici, le dire.
